Source notes

References

Temple Trail Guide is an independent student project. Destination names are presented for general discovery; schedules, access, and visitor requirements can change. Confirm current details directly with the official directory before travelling.

Temple information

  • The Church of Jesus Christ of Latter-day Saints. Official Temple List. Source for the worldwide directory names, locations, and building statuses. Accessed October 9, 2026.
  • Accra Ghana Temple. Official temple profile and source for the homepage hero photograph. Accessed October 8, 2026.
  • Aba Nigeria Temple. Official temple profile. Accessed October 8, 2026.
  • Johannesburg South Africa Temple. Official temple profile. Accessed October 8, 2026.

Visual assets

  • Worldwide temple-card photos use the official photo displayed on each linked temple profile when available. Dedicated temples without a profile photo use the locally stored Accra Ghana Temple image, explicitly labeled as a representative photo and not as an image of that temple. Announced temples are shown without a photo. Other profiles without an image identify the photo as unavailable. Available directory photos are lazy-loaded as visitors browse the catalog. The locally stored destination-card photos and Accra Ghana Temple images were downloaded from the official "Download Photo" links on their temple profiles.
  • Temple Trail Guide's logo is an original inline SVG created for this student project.

Typography

  • Google Fonts. DM Sans and Playfair Display. Used for body text and headings.
